## 💡 项目立意 (Idea & Insight)

入职第一天不知去哪吃饭的尴尬、团建时刷手机的疏离感、犯错时的羞耻感……这些微小的瞬间在钢铁大厦的工位里消磨着职场新人的期待。

**"I see you, 实习生"** 不教你写周报，也不教你如何成为一个“高效工具人”。它伪装成抖音视频流里的 AI 电台，通过 **“会共鸣的便利贴墙”** 和 **“上班搭子”**，在你想逃离的瞬间提供一个可以自嘲、被看见、被接住的情绪角落。

---

## ✨ 核心功能与场景 (Key Features)

### 1. 💥 闯祸电台 (PM 66.6) —— “原来我们都一样”
* **便利贴墙与共鸣回响**：展示别人的“闯祸大赏”（发错邮件、叫错领导名字等），支持一键投出情绪票（`我也干过！` / `还有高手？！` / `笑发财了`），看到同频共鸣人数。
* 🛡️ **“领导来了”一键伪装**：轻轻一按彩蛋按钮，界面瞬间切换为**高仿真 Excel 表格**，神不知鬼不觉，幽默安全摸鱼。

### 2. 🌙 治愈电台 (PM 88.8) —— “给你一个上班搭子”
* **无考核的温暖字句**：轻柔声波包裹，只有一句“辛苦了，今天也很棒”。
* 🤖 **AI 接线员 / 真人搭子匹配**：通过共情算法接住情绪，或根据便利贴墙上的共鸣经历匹配真实的实习生搭子，打破城市孤独。

## 🚀 本地运行指南 (Run Locally)

### 环境要求
* **Node.js** (v18+)

### 步骤
1. **安装项目依赖**：
   ```bash
   npm install

```

2. **配置环境变量**：
在根目录下创建（或编辑） `.env.local` 文件，填入你的 Gemini API Key：
```env
GEMINI_API_KEY=your_gemini_api_key_here

```


3. **启动开发服务器**：
```bash
npm run dev

```
